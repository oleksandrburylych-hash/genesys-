# Исходники компендиумов

Каждая папка — один компендиум (`packs/<имя>` после сборки). Внутри — JSON-файлы с массивами документов,
по файлу на источник (`core.json` — Core Rulebook, `epg.json` — Expanded Player's Guide).

Сборка: `npm install && npm run build:packs` — пересобирает `packs/` и обновляет список компендиумов в `system.json`.
Идентификаторы документов стабильны (вычисляются из имени), поэтому пересборка не ломает ссылки.

Формат документа:

```json
{ "name": "Русское имя", "nameEn": "English name", "type": "talent", "folder": "Папка",
  "system": { "tier": 1, "activation": "passive", "ranked": false, "description": "<p>…</p>", "source": "Core Rulebook, с. 72" } }
```

Противники (`adversaries`) дополнительно содержат `items` — вложенные навыки, оружие, таланты, способности.

Описания — краткие пересказы механики своими словами, а не текст книг.
