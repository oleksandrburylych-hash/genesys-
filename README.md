# Genesys RPG для Foundry VTT v14

Система для игры по **Genesys** (Narrative Dice System) в Foundry Virtual Tabletop **v14**.
Написана с нуля на современном API: `TypeDataModel`, `ApplicationV2`, `ActorSheetV2`/`ItemSheetV2`.

> Статус: **0.14.2.** Компендиумы: Core Rulebook (по официальному русскому переводу Hobby World),
> Expanded Player's Guide, Realms of Terrinoth и Zynnythryx's Guide to Magic. Большая часть рутины автоматизирована.

## Оформление

Листы — в стиле официального листа персонажа из книги: бордовые «щиты» поглощения, ран, усталости и защиты,
медальоны характеристик на золотой полосе, ленты-разделители, таблицы навыков в две колонки со шкалой ранга
из шевронов, пирамида талантов. Шрифты Oswald и Roboto Condensed (OFL, с кириллицей).

У каждой записи компендиумов есть картинка: символы из коллекции [game-icons.net](https://game-icons.net)
(CC BY 3.0) на плашках в цветах категорий подбираются по названию (`tools/icon-rules.mjs`,
атрибуция — `assets/icons/gi/CREDITS.md`). Свои картинки можно поставить щелчком по изображению предмета или актёра.

## Миры и типы приключений

У каждого предмета, противника и транспорта есть **теги миров** (`system.worlds`): Фэнтези, Эпоха мифов, Терринот,
Стимпанк, Моровая война, Современность, Мир чудовищ, Постапокалипсис, Зомби-апокалипсис, Научная фантастика, Космоопера.
Теги видны в шапке листа предмета/противника и правятся там же (без тегов — «любой мир»). Правила разметки — `tools/world-rules.mjs`.

**Тип приключения** — набор миров и навыков (`module/worlds.mjs`): Фэнтези, Терринот, Эпоха мифов, Стимпанк, Моровая война,
Современность, Мир чудовищ, Пустоши, Зомби-апокалипсис, Научная фантастика, Космоопера, «Все книги» и свой набор миров.
Одноимённые предметы разных книг не дублируются: остаётся версия, родная миру (меч Терринота в Терриноте, меч Core в фэнтези).

Для зомби-апокалипсиса добавлены 4 **домашних** противника (в книгах Genesys зомби нет) — они помечены как домашний материал.

## Мастер настройки мира

При первом запуске мира ведущему открывается мастер. Открыть снова: кнопка «Мастер настройки мира Genesys» во вкладке
«Настройки» боковой панели, команда `/genesys` в чате, кнопка с палочкой на панели инструментов или Настройки → Genesys RPG.

Ведущий выбирает **типы приключений** (один, несколько, свой набор миров или «Все книги»), книги и что импортировать —
в мир попадает только подходящий контент, со счётчиками прямо на карточках. Выбранные приключения запоминаются:
по ним мастер создания персонажа сам отбирает расы, карьеры и навыки — игроку ничего выбирать не нужно. Также создаются таблицы бросков критических травм и попаданий,
журнал «Genesys: справочник», макросы на панели ведущего и стартовые очки сюжета.

## Что система делает сама

- **Атака по цели** (наведение клавишей T): сложность по дистанции между токенами, защита цели → кости штрафа,
  талант «Противник» → усиление, лежачая цель, стрельба вплотную, цель вплотную с союзником, перегруз,
  дезориентация, штрафы критических травм.
- **Урон** одной кнопкой по цели: поглощение, Проникающее, Бронебойное, Оглушающий урон; выведение из строя,
  выбывание приспешников и соперников, автоматический бросок критической травмы.
- **Свойства оружия** активируются кнопками в карточке броска (Дезориентация, Нокдаун, Сковывание, Жжение…),
  состояние вешается на цель значком.
- **Трата символов**: под каждым броском — подходящие строки таблиц (бой, социальные сцены, магические неудачи).
- **Встречные проверки**: Обаяние, Обман, Запугивание, Лидерство, Переговоры, Скрытность — сложность из навыка цели.
- **Лечение**: Медицина по цели — сложность по её ранам, раны и усталость снимаются; отдых после сцены,
  ночной отдых, излечение травм.
- **Очко сюжета** прямо в окне броска; **слоты инициативы** — игроки сами выбирают, кто ходит в слоте ПИ.
- **Таланты с числами** (Закалённый, Упорство, Оборона, Выносливость, Крепость) меняют показатели сами.
- **Мастер создания персонажа** (9 шагов, обычное создание без выбора паков): игрок видит только расы, карьеры, таланты
  и героические способности приключений, которые ведущий выбрал в мастере настройки мира (если их несколько — карьеры
  и навыки подстраиваются под мир выбранной расы); на лист попадает только набор навыков приключения, карьерные навыки
  подстраиваются под мир («Ближний бой» → «Ближний бой (лёгкое оружие)» в фэнтези);
  бесплатные карьерные и стартовые ранги, покупка характеристик и навыков за опыт со счётчиком, таланты по правилу пирамиды,
  мотивации по таблицам d100, героическая способность, описание, 500 стартовых монет и стартовое снаряжение карьер Терринота.
- **Модификации** перетаскиваются на оружие и броню, занимают точки улучшений и меняют характеристики.

## Медицина по правилам (0.14.2)

- Кнопка **«Медицина»** (стетоскоп) в шапке листа и на панели токена: лечит выбранную цель или себя. Если у пациента есть критические травмы — выбор: раны или конкретная травма.
- **Раны** (Core, табл. I.3–3): сложность лёгкая / обычная / сложная по ранам пациента; каждый успех — рана, каждое преимущество — усталость; «Хирург» — +1 рана за ранг; лечение применяется само, карточка броска показывает итог.
- **Критическая травма:** сложность = тяжесть; успех — травма вылечена (её эффекты снимаются). Кнопка на строке травмы теперь лечит Медициной: выделенный токен другого персонажа или сам пострадавший.
- **Ограничения книги** (предупреждение, решает ведущий): одна проверка Медицины на пациента за встречу; одна попытка одного лекаря на травму в неделю игрового времени; лечить себя — сложность +2 (раньше ошибочно было «усиление ×2»); без аптечки — +1 кость штрафа.
- Щелчок по навыку «Медицина» при выбранной цели запускает лечение.

- **Вкладка «Толкования» в ширме ведущего:** что может значить **преимущество, осложнение, триумф и крах** в проверке каждого навыка — по 10 вариантов на каждый исход, для трёх эпох (**средневековье, наше время, будущее**). 33 навыка, 3720 вариантов: конкретные сцены с подсказками по механике там, где они уместны. ## Снаряжение по правилам (0.13.2)

- **Нагрузка:** надетая броня весит на 3 меньше (только один экземпляр); рюкзак при персонаже даёт +4 к порогу (несколько рюкзаков не складываются — действует лучший); одежда, плащи и сапоги — «надетая имеет нагрузку N» (кнопка «надеть» у таких предметов); «нагрузка указана за 5 штук» для пайков и т. п. Перегрузка на величину Силы и больше — подсказка «нет свободного манёвра».
- **Броня и защита** (Core, «Поглощение», «Ближняя и дальняя защиты»): учитывается один надетый комплект брони, лишние подсвечиваются; «Оборонительное» и «Отражающее» у оружия в руках добавляют защиту; защита не выше 4.
- **Киберимпланты:** имплантированная броня +1 к поглощению, киберглаза +1 к Бдительности и Вниманию, снижение порога усталости; импланты дают к параметру не больше +1. Бонусы можно задать вручную в листе предмета.
- **Стопки:** одинаковое снаряжение (и гранаты) складывается в одну стопку при получении — перетаскиванием, из лавки, из добычи. Оружие и броня не складываются.
- **Болеутоляющее:** кнопка в шапке листа и на панели токена. Лечит 5 ран, каждое следующее за день на 1 меньше, шестое не действует; «Знаток болеутоляющих» добавляет по ране за ранг; можно лечить выбранного токеном союзника; предмет расходуется, счётчик сбрасывает ночной отдых. Эликсир бодрости работает так же для усталости.
- Свойства снаряжения определяются по тексту предмета; в листе предмета их можно переопределить.

I.6–10): «Остолбенение» вешает состояние, «Удручающая рана» передаёт очко сюжета, «Звон в ушах» и «Мучительная рана» добавляют сложность к проверкам своих характеристик, «Слепота» усиливает сложность, «Ужасная травма» и «Чудовищная травма» бросают d10 и снижают характеристику (временно / навсегда), «Кровотечение» отнимает раны и усталость в начале хода. ## Модули и фанатские дополнения (0.11)

В мастере настройки мира ведущий выбирает:
- **Фанатские книги Genesys Foundry:** Creature Catalogue (122 существа), Equipment Encyclopedia (снаряжение Shadow of the Beanstalk
  и импровизированное оружие), To Protect and Serve (полицейский сеттинг: 7 карьер, таланты, снаряжение, транспорт, противники,
  3 навыка Знания, способности архетипов).
- **Модули правил** (по умолчанию выключены): «Использовать пси» (PSI — архетипы, карьеры, 3 пси-навыка, 26 пси-сил, 52 таланта,
  снаряжение, противники, страница о мирах и фракциях), «Расширенные правила страха» (таблица трат символов страха),
  «Использовать набор дополнительных талантов» (Talents Expanded — 364 таланта; в мастере персонажа показываются только
  подходящие миру приключения).
- Выключенная книга или модуль не импортируются и не появляются в мастере персонажа, лавке, мастерской и ширме ведущего.

Также в 0.11: свои цветные значки состояний и значки активных состояний на листах (щелчок — снять, цифра — сколько ходов
осталось); **проверка страха** (ширма ведущего или макрос: карточка в чат, каждый бросает Выдержку, эффект Core —
кнопкой); **социальная сцена** (давление на цель до компромисса и капитуляции, критические замечания, раскрытие мотиваций);
**ответный удар** Парирования (улучшенного) и Контратака.

## Новое в 0.10

- **Длительность состояний:** Дезориентация, Сковывание, Ошеломление и Жжение от свойств оружия длятся рейтинг раундов
  и снимаются сами; Жжение наносит урон в начале хода цели. Конец боя снимает их.
- **Реакции:** Парирование (и Блок со щитом) — карточка «Парировать / Принять удар» перед уроном; Уклонение — кнопки
  в окне атаки; Оборонительная тактика и Шаг в сторону — кнопка на таланте, усиливают атаки по персонажу.
- **Ширма ведущего** (кнопка с книгой-черепом): конструктор встреч из противников приключения (на сцену и в бой),
  выдача опыта группе с записью в журнал, справка по сложностям, дистанциям, состояниям и трате символов.
- **Фильтр миров** в окнах компендиумов.
- **Мастер персонажа:** лавка стартового снаряжения на бюджет (Core — 500) и карманные d100, кнопка «Случайный персонаж»,
  правило «магия только карьерная» (настройка: авто для Терринота / всегда / никогда).
- **Своё приключение** в мастере настройки мира: название и набор навыков.
- **Экспорт/импорт персонажа** в файл (кнопки в шапке листа).
- **Бой транспорта** по Core: Ускорение, Торможение, Перестроение, Уклонение, Подготовка к удару, Получение преимущества
  (сложность по скоростям), Опасное вождение, штраф местности.
- **Скакун** на листе персонажа: перетащите животное-противника; сесть/спешиться, Верховая езда, атака скакуна.
  В компендиум добавлены 4 скакуна Терринота.
- **Мастерская** (молот в шапке листа): ремесло и алхимия Терринота — сложность по редкости, время, материалы,
  таблицы трат символов, предмет появляется у персонажа.

## Возможности

### Нарративные кубики
- Шесть кубиков Genesys как полноценные термы Foundry: `da` (способность), `dp` (мастерство),
  `db` (бонус), `di` (сложность), `dh` (испытание), `ds` (помеха).
- Окно сборки пула: добавление/удаление кубиков, улучшение и ухудшение по правилам,
  выбор сложности одной кнопкой, выбор видимости сообщения.
- Карточка броска в чате: выпавшие грани, итог после сокращения символов, успех/провал.
- Атака оружием: урон = базовый урон (+Сила) + чистые успехи, подсказка о возможности крита,
  кнопка «Нанести урон выделенным» (с учётом поглощения).
- Инициатива: проверка Бдительности или Хладнокровия (настройка), порядок — успехи, затем преимущества.

### Персонаж
- Шесть характеристик, навыки по категориям с предпросмотром пула прямо на листе.
- Автоматический расчёт: порог ран и напряжения, поглощение, защита, нагрузка.
- **Создание персонажа**: перетащите архетип — проставятся характеристики, базы порогов и стартовый опыт;
  перетащите карьеру — отметятся карьерные навыки.
- **Режим создания**: характеристики покупаются за опыт (10 × новое значение), ранг навыка — максимум 2.
- **Журнал опыта**: каждое повышение навыка/характеристики и покупка таланта списывает опыт по правилам
  и записывается в журнал; удаление записи возвращает опыт. Автоматизацию можно отключить.
- **Пирамида талантов**: таланты сгруппированы по уровням, правило пирамиды проверяется при покупке,
  ранжированные таланты повышаются повторным перетаскиванием (каждый ранг — на уровень выше).
- Снаряжение: оружие, броня, предметы, деньги, нагрузка (надетая броня весит на 3 меньше).
- Мотивации (сильная сторона, недостаток, желание, страх), внешность, биография, заметки.

### Противники
- Прислужники, соперники, заклятые враги.
- У прислужников ранг групповых навыков считается от числа живых в группе.

### Магия
- Вкладка «Магия» на листе персонажа: магические действия и готовые заклинания.
- Конструктор заклинаний: навык, дополнительные эффекты (с ограничениями по навыкам и повторяемыми),
  магический фокус; сложность считается автоматически и не превышает Запредельную; бросок, 2 усталости,
  урон Атаки (характеристика навыка + успехи + фокус), сохранение сочетания как готового заклинания.
- Редактор эффектов в листе заклинания.

### Транспорт
- Тип актёра «Транспорт»: фигура, скорость, манёвренность, защита, броня, повреждения корпуса,
  перегрузка систем, экипаж, вместимость. Оружие с секторами обстрела.
- Проверки управления и стрельбы — от лица члена экипажа (выделенный токен или назначенный персонаж).
- Бросок критического попадания по своей таблице.

### Dice So Nice
- Если модуль установлен, нарративные кубики выпадают в 3D в цветах Genesys с символами на гранях
  (картинки граней — `assets/dice`, силуэты — `assets/dice/shape`, генератор — `tools/dice-art.mjs`).

### Очки сюжета
- Окно трекера (кнопка на панели токенов). Игроки тратят очко — оно уходит Мастеру, и наоборот.
  Работает через сокет, сообщает в чат.

### Типы предметов
`skill` навык · `talent` талант · `ability` способность · `archetype` архетип · `career` карьера ·
`weapon` оружие · `armor` броня · `gear` снаряжение · `quality` качество · `injury` критическое ранение

## Установка

В Foundry VTT v14: **Game Systems → Install System**, в поле **Manifest URL** вставьте:

```
https://github.com/oleksandrburylych-hash/genesys-/releases/latest/download/system.json
```

Ссылка всегда ведёт на последний релиз; обновления Foundry предложит сам.

**Выпуск новой версии:** поднять `version` в `system.json`, закоммитить и запустить Actions → Release → Run workflow (или отправить тег `vX.Y.Z`) —
GitHub Actions (`.github/workflows/release.yml`) соберёт архив и опубликует релиз.

## Макросы

```js
// Открыть окно броска с пулом
game.genesys.roll({ ability: 2, proficiency: 1, difficulty: 2 });

// Проверка навыка выделенного токена / назначенного персонажа (по ключу или имени)
game.genesys.rollSkill("perception");

// Бросок без окна
const pool = new game.genesys.DicePool({ ability: 3, difficulty: 2 });
game.genesys.DicePoolDialog.rollPool(pool, { label: "Проверка" });
```

## Структура

```
system.json            манифест
genesys.mjs            точка входа
module/config.mjs      справочники: характеристики, навыки, сложности, стоимость опыта
module/data/           модели данных актёров и предметов
module/documents/      логика актёра (броски, опыт, архетип/карьера/таланты), предмета, участника боя
module/dice/           нарративные кубики, бросок, пул
module/apps/           окно броска, трекер очков истории
module/sheets/         листы персонажа, противника, предмета
templates/             Handlebars-шаблоны
styles/genesys.css     стили
lang/ru.json, en.json  локализация
assets/icons/          иконки символов (собственные SVG)
```
